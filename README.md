Order App - restraurant online ordering system

To start we brainstormed and then came together to discuss our ideas eventually we settled on a website for restaurant that would allow them to have a personalised online experience, the website would allow customers to view menus place orders for deliveries or pick up and make reservations at the restaurant. It will also include an admin side to manage all these features effectively. To develop this idea we are using agile scrum methodologies.

The key objectives of our website are:
Increase restaurant online visibility.
Provide a convenient ordering experience for customers.
Streamline order and reservation management for staff.

Elevator pitch: Cutting out the expensive middle-men of Deliveroo and Uber Eats to provide a direct service to the customer through deliveries, menus and reservations.

Before work could start on the project we needed to clearly state what was in scope for our project and what was out of scope to ensure the team knew what the website would do and what it wouldnt.

In Scope
Online ordering for delivery and pickup.

Interactive menu with images and prices.

Table reservation system.

Responsive web design for mobile and desktop.

Customer feedback form.

Admin dashboard for managing menus, orders, and reservations.

Out of Scope
Delivery logistics and driver management.

Marketing and promotional campaigns.

Loyalty or rewards programs.

Once this was sorted we decided on what we would be using to complete the project we settled on:

Frontend: HTML, CSS, JavaScript

Backend: PHP

Database: MySQL

Version Control: GitHub

Design: Figma

Following the agile SRCUM method we orgainised the workload into sprints containing 12-14 story points per sprint.
We used jira to create our sprints assign the workload and create our burn down chart allowing us all to see what work needed to be completed and when it was needed by.

Sprint	Focus Features
Sprint 1	User Login & Registration, Database Setup
Sprint 2	Menu System, Shopping Cart
Sprint 3	Admin Panel, Checkout & Payment
Final Week	Comprehensive Testing, Bug Fixing, and Demo Preparation
